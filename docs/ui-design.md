# Mandala 界面设计与审核约定

面向每天实际使用的 Agent 工作台。界面优先帮助用户判断当前对象、下一步操作和执行结果，阅读实现解释不是主要流程。

## 已选定的设计基准

2026-10-29 用户确认紧凑工作台与 C 单色六瓣标志。当前设计权威为根目录 [DESIGN.md](../DESIGN.md)、[C 品牌资产](brand-c.md)、[组件契约](ui-components.md) 与 [整合验收记录](ui-rebuild.md)。之前的 Cursor、石墨朱印及黑珊瑚方案是历史参考，不能覆盖当前的中性配色、紧凑密度和页面关系。历史设计参考留在本地，不随源码发布。

外部参考提供设计依据，不代替 Mandala 的业务模型、实际组件契约或真实页面验收。历史适配记录不作为当前实现规范。

当前标志保留六瓣拓扑与开放留白，使用中性单色，不使用朱红强调色。完整标志、小尺寸光学校正、favicon、桌面与托盘资产按同一几何来源维护。侧栏、开始页与其他品牌入口使用同套资产；旧品牌文件只用于历史对照。

## 补充交互依据与取舍

- [Linear 2026 设计复盘](https://linear.app/now/behind-the-latest-design-refresh)：稳定页头和操作位置、区分导航与内容、减少无意义分隔。Mandala 采用用户认可的紧凑方向，保留自身的 Agent、Task、Chat 与 Project 模型。
- [Linear 2024 设计过程](https://linear.app/now/how-we-redesigned-the-linear-ui)：同时检查导航、标题、面板和密度；设计需通过真实使用持续校正，局部改间距不足以建立整体秩序。
- [Primer FormControl](https://primer.style/product/components/form-control/)：标签、输入、帮助和校验各有职责。每个字段必须有可见标签；占位文字不承担标签职责。
- [Carbon Loading](https://www.carbondesignsystem.com/building-blocks/core/components/loading/guidelines)：逐步读取内容优先骨架屏，局部读取不阻塞已就绪的主体。
- [W3C 状态消息](https://www.w3.org/WAI/WCAG21/Understanding/status-messages)：保存和等待状态无需抢夺焦点即可被辅助技术识别；错误使用清楚的通知。
- [Carbon Accordion](https://www.carbondesignsystem.com/building-blocks/core/components/accordion/guidelines)：折叠适合可选补充内容，必读内容与主要操作不能藏进去。复杂工具执行记录保留其专用展开组件。

这些来源解释设计决策，不能证明 Mandala 已达到同等视觉质量。视觉判断必须来自本产品同一状态的实际页面。

## 页面骨架

| 页面类型 | 主区域 | 属性 / 补充区域 | 主要操作 |
| --- | --- | --- | --- |
| 任务详情 | 任务记录、完成要求、Agent 交付、执行历史 | 负责人、验收方式、指派；上下文面板放技术标识和说明 | 顶部操作带开始 / 完成 / 停止；取消是次要操作 |
| 任务与资料列表 | 搜索、筛选、列表 / 看板 | 分组数量与简短状态 | 待办录入或导入按钮，不能用大块帮助抢占页面 |
| Agent / 项目设置 | 对象选择、内容标签、当前表单 | 正常时隐藏保存提示，能力与来源按需查看 | 等待、保存中与错误在页头；必填字段直接可见 |
| 文档与交付物 | 内容预览、版本反馈 | 固定版本、来源、权限、引用、诊断 | 编辑与资料设置是明确按钮，不伪装成说明标题 |
| 记忆 | 层级概览、筛选、紧凑记录、完整内容入口 | 来源和加工历史 | 整理 / 纠正；摘要不改写原始内容 |
| 市场 / Projects / Agents | 搜索与浏览 / 独立对象目录 | 详情、来源及关联 | 安装、关联和进入完整详情有明确目标 |
| 对话 | 消息与输入框 | 执行过程、文件、实际配置 | 发送与中断围绕输入区域，不能强行套设置页骨架 |

任务记录不等于已知 LLM 输出；来源信息不足时不能标成 AI 生成。Agent 回执可明确标为 Agent 输出。产品帮助有独立位置，不能混成任务正文。权限与未知执行状态的警告仍保持可见。

## 共用设计规则

1. 使用 `src/ui/tokens.css` 的角色变量；共用间距 4 / 8 / 12 / 16 / 24 / 32，桌面控件与面板默认圆角 5、控件最小高度 30，触控目标至少 40。弹层圆角至少 8；显式保存的用户圆角（包括 0）、密度和其他外观偏好保持有效。默认灰白与炭黑，不使用偏黄、奶油色或暖灰底色；颜色只表达真实状态。首次访问默认浅色，保留已保存的明暗偏好。
2. 默认界面字体为本地 Inter Variable，中文依次使用 Noto Sans SC 与 PingFang SC。界面 13、元数据 12、阅读和消息正文从 14 起并保持舒适行高；页面标题 20 / 600，章节标题 15，开始对话标题可用 24。字体、字距及内边距消费共享角色，不在业务页面另定一套。紧凑不是等比缩小，正文不能为塞入更多字降到脚注字号。
3. 产品导航是有悬停、焦点和图标的真实链接。图标使用 `ui/Icon`，不使用箭头字符或浏览器默认下划线。用户 Markdown 链接保留内容语义。
4. 面板表达对象边界，间距表达章节边界。细分隔线只用于同一对象内部的属性或列表行，不在每节前后任意加线，也不把所有段落套卡片。
5. 选框统一使用 `ui/Select`；箭头位置随共享控件内边距，长值截断，选项可搜索，窄屏弹层限制在视口内。使用组件已有键盘和焦点行为。
6. 可选帮助、来源细节和历史使用 `ui/Disclosure`，统一末尾箭头、整行点击和焦点。指派、验收、重新打开等业务操作直接显示；需要展开的编辑器由明确操作按钮开启。
7. `ui/tokens.css` 与运行时主题统一颜色、字体、形状和控件尺寸；shadcn/ui Radix 原语和 Tailwind CSS 4 通过 Mandala 语义变量及 `ui` 包装层提供控件，`WorkspacePage` 等业务组件提供共用布局。页面 CSS 负责业务排布，不复制控件实现，不引入另一套配色或焦点管理。避免全局 reset 破坏既有内容与原生控件语义。

## 工程检查与视觉检查

`tests/ui-design-contract.test.ts` 通过 TypeScript AST 阻止新增原生 select、未经管理的 details 和箭头字符导航。它只约束上述组件回退，不能验证美观，也没有假装约束所有 CSS 值。

E2E 验证真实行为：指派保存与刷新、正文 / 帮助边界、状态对应的操作、键盘选择与中文输入、焦点恢复、版本切换、草稿保留、390 / 768 / 1024 / 1440 下的可用性。不要只断言 CSS 类名或截图数量。

设置编辑自动保存：输入停顿后串行提交，保存期间可以继续编辑；正常时隐藏已保存提示；等待、保存中和错误保留反馈。失败保留草稿，冲突必须重新读取，不能自动覆盖其他地方的修改。项目入口默认概览，背景、资源和成员是明确的编辑页签。取消新增对象与删除已有对象仍是显式操作。

列表的时间必须有明确含义：Tasks 显示真实活动时间，并以同一时间排序和判断最近使用窗口；详情保留创建时间。Library 区分最近访问、编辑和发布；按最近活动排序时明确标注，不把浏览时间伪装成修改时间。记忆默认按更新时间倒序，类型是平行筛选，不以 L0–L3 递进图承担导航。加工结果由用户主动打开，生成说明在底部。

首次读取用共用 `ui/LoadingState` 占位，只有成功读到空列表才显示空态；后台记录慢或失败不阻塞已加载的主体内容。轮询不重叠，隐藏页面暂停，完成结果不自动抢占主体。

逐页视觉审查需要：

- 先列问题：位置、触发条件、用户影响、优先级；不能先改一批 padding 再反推问题。
- 桌面同视口同数据比较前后，窄屏另看重排；数据加载完成后才能作为最终截图。
- 展开选框、帮助、详情和编辑器；覆盖长标题、长路径、多对象、空状态、错误、禁用、执行中、等待验收和完成。
- 检查标题到正文的阅读顺序、操作优先级、分组理由、对齐、控件内边距、滚动区域、文字来源区分、主题和焦点。
- 逐张查看，不把 DOM 无溢出视为视觉通过。为每页记录截图、发现、修正和未验证状态。
- 有截断、加载未结束、遮挡、未知真实状态的截图标为无效证据，重新采集。没有可检查的状态不得写“已通过”。

本地用户数据截图放任务的外部审核目录，不能提交个人历史或运行数据。可提交的自动化测试使用隔离的临时 HOME 和合成数据。需要视觉快照时也必须使用合成数据，并由人审阅基准更新；不能用更新基准绕过退化。

## 完成边界

代码审查、行为检查、逐页视觉检查和用户接受是四种不同证据。自动化减少可重复错误，不能保证设计绝不出问题，也不能替用户宣布喜欢。预览、开发源码、正式服务分别记录；没有发布授权时不得把预览变化说成正式服务已更新。

## 2026-10-26 设置修正
外观与已有 Runtime 配置使用自动保存；新建接入、停用、导入导出仍是明确动作。独立布尔设置沿用共享 switch。侧栏固定与排序使用紧凑行及拖动手柄，上下方向键可排序。模型字段合为一个可搜索、可输入自定义 ID 的 Select；标签和控件上沿、行高保持一致。快捷键总览放通用设置，用户菜单按钮与链接同一行样式。
