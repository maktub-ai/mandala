# 记忆检索与上下文

本次任务起点：`fbc2079de327f20291feaf30cef6a94561590aa6`。本文说明检索策略和接口边界，不代表最终提交、测试或安装验收记录。

## 关键词默认与向量开关

新安装与升级后的已有工作区默认使用 BM25 关键词检索；已有向量缓存不会自动启用向量检索。手动搜索、Agent 搜索、自动召回、生成阶段候选排序及后台索引均遵守开关，关闭时不探测或调用嵌入服务。记忆生成与读取开关保持独立。

在 **设置 → 系统 → 记忆检索** 中显式开启，选择 Ollama 或 OpenAI 兼容接口，并填写服务基础地址与嵌入模型。未预填任何地址或模型；无需安装指定的模型管理器。OpenAI 兼容地址应包含服务要求的路径（例如 `/v1`），系统追加 `/embeddings`；Ollama 地址追加 `/api/embed`，通过 `/api/tags` 核对所选模型的摘要。接口分别遵循 [Ollama embeddings](https://docs.ollama.com/api/embed) 与 [OpenAI embeddings](https://developers.openai.com/api/reference/resources/embeddings/methods/create) 的请求格式。

- 开启并保存后，授权范围内的记忆正文和检索词会发往用户选择的地址；远程服务会接收这些文本，并可能计费。不开启时没有嵌入请求。
- API Key 可选，保存在当前工作区私有 `memory-retrieval.json` 中，不进入通用配置、对话或设置查询响应；留空保留，勾选删除可清除。更换服务地址或提供方时不沿用旧密钥。离线备份包含该配置文件，应按凭据保管。
- 关闭或更改配置会中止旧请求；正在返回的旧向量不写入缓存。关闭不删除记忆，也不删除已有缓存。
- 服务地址、提供方、模型及凭据身份隔离缓存；Ollama 模型摘要变化也会重建对应索引。维度从实际返回值校验，不固定为 768；发送原始分块文本，不套用特定模型的提示前缀。
- 向量开启后，原有 RRF 排序、权限复核和检索预算继续生效；不再应用仅针对旧模型校准的相似度门槛，以免新模型的分数分布误删关键词命中。模型的语义质量仍需实际语料验收。后台分批建索引，索引不完整或服务失败时仍可关键词检索，并由搜索结果标识降级。
- 这些设置仅由本机用户界面修改，不开放给 Agent 业务工具或远程网页。

## 何时自动检索

- 实质性请求默认检索，避免仅依赖关键词触发而漏掉相关记忆。
- 纯确认、感谢和问候跳过搜索；当前项目与 Agent 的 L3 工作原则仍可进入上下文。
- 继续旧工作或询问历史决定时，查询补充最近两条有效用户请求，跳过纯确认和空泛的继续指令。
- 任务请求作为补充，保留当前请求中出现的新问题或实体；查询不使用助手和工具输出冒充用户输入。
- 查询限制为 2,000 个 UTF-16 字符，截取时保留完整 Unicode 代理对。

## 自动注入的统一预算

- 分层记忆正文先转为摘录，与版本、时间、验证类型、来源数量及失效通知共同装入一个上下文包。
- 包含指引与序列化元数据在内，整个包最多 **6,000 UTF-8 字节**；这是确定性的文本预算，不是精确模型 token 数。
- 最多注入 8 条：当前 L3 优先，随后 L1 事实与 L2 场景交替，保留各层内部的召回顺序并去重。
- L3 摘录最多 400 个 Unicode 字符，事实与场景摘录最多 320 个；最终仍受统一字节预算限制。
- 修订或撤回通知只含记录 ID、当前修订和状态，不再携带完整正文。通知过多时明确提示存在省略，要求使用先前记忆前重新读取。
- 所有历史内容均为参考资料，不构成新指令或当前状态证明；截断部分不能靠推断补全。

## Agent 摘要搜索与按需深读

- `memory search` 返回最多 500 个 Unicode 字符的命中摘录及元数据，包含记录 ID、修订、层级、时间、验证类型、匹配理由和截断标记。
- 搜索结果不携带完整正文或整组证据；长记录不会仅因其完整正文超过搜索预算而在 Agent 搜索中消失。
- `memory read <recordId>` 读取当前完整记录，包括正文、`support` 原话、`evidence` 引用和 `dependencies`。
- 涉及历史决定、偏好、旧任务续接、缺少参数或记忆冲突时，Agent 应主动搜索；摘录不足以支持判断时读取全文，必要时沿依赖记录继续核对事实。
- 引用仍不足时，应查阅实际授权的原始来源；不能补造证据。此次没有向 Agent 开放整段 `memory source` 原始来源读取，也不扩大项目或 Agent 权限。

## 保留的边界

- 人类使用的 HTTP 搜索与资料浏览保持兼容；摘要协议用于 Agent 搜索和自动上下文。
- 读取开关、有效期、修订、来源权限及依赖校验继续生效。
- 此次不调整记忆生成和存储，不优化搜索链路中的同步向量索引刷新，也不安装或更新本机 App。
- “已提供给模型”的记录仍不能证明模型实际采纳或回答正确；验收应分别观察相关记忆进入上下文、旧信息误用、上下文体积和响应耗时。
