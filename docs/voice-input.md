# 语音输入

在「设置 → 通用 → 语音输入」主动启用并保存。聊天输入框会显示麦克风按钮：点击录音，再点击停止，识别结果追加到已有草稿；编辑确认后手动发送。每次最多 2 分钟。取消、离开页面或切换对话会停止录音和当前转写，保留已有草稿。

## 本地识别

- 轻量：Whisper Base Q5，约 60 MB。
- 标准：Whisper Small Q5，约 190 MB，默认选择；通常比 Base 更准确，但需要更多计算资源。

两档均为多语言模型，可选择中文、英文等语言或自动识别。模型在设置中按需下载、取消或删除。首次下载需要访问 Hugging Face；下载完成后校验固定 SHA-256，识别时再次校验。模型不会随安装包下载，也不会在本地识别失败时切换到云端。

本地识别使用 whisper.cpp 的独立子进程，录音临时文件在请求结束后删除。模型保存在 Mandala 数据目录的 `voice-models/`。进程异常退出可能留下临时文件，可在服务停止后删除其中的 `recording-*` 目录及 `.part` 文件。首版已在 Apple Silicon Mac 验证；其他平台尚未完成真机验收。不提供实时流式字幕。

## 云端识别

选择 OpenAI，填写自己的 API Key 并保存。录音会发送到 OpenAI 的 `/v1/audio/transcriptions`，使用 `gpt-transcribe`，按服务商 API 价格计费；ChatGPT 订阅不等同于 API 额度。首版只支持此服务商，无自定义服务器地址。

API Key 保存在本机数据目录的 `voice.json`，文件权限为 `0600`，未额外加密。浏览器只能读取是否已配置，不能读回密钥；留空保存保留原密钥，勾选删除则清除。请将数据目录及其备份视为敏感资料。

## 权限与验证边界

只有点击录音时才请求麦克风；桌面 App 仅允许其受信任的主窗口请求音频权限。远程网页入口不开放语音接口。麦克风权限被拒绝时，可在系统设置中重新允许。

自动测试覆盖设置、密钥不回显、模型下载校验、音频格式及大小、取消、草稿保留、模式切换和麦克风权限。云端协议使用模拟响应验证，真实付费 API 调用需要用户自行配置有效密钥。
